# Previsión de demanda de neumáticos

Proyecto end-to-end de ciencia de datos: predicción de demanda semanal por
referencia para apoyar decisiones de compra en un distribuidor mayorista.

**Estado:** en construcción.

## Qué resuelve

Cada semana, el responsable de compras decide cuántas unidades pedir de cada
referencia. El proyecto sustituye la estimación manual por una previsión a 4
semanas y un stock de seguridad calculado.

## Stack

Python · pandas · scikit-learn · LightGBM · Azure Machine Learning

## Estructura

- `src/` — código del proyecto
- `notebooks/` — exploración
- `docs/` — documentación y decisiones
- `data/` — datos (no versionados)
